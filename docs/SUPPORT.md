# Support and diagnostics

Describe the version, action, expected result and observed result in an ordinary
issue. Use [private vulnerability reporting](../SECURITY.md) for security issues.
Never post credentials, private signing keys or personal save archives publicly.

Settings offers an explicit "Export debug bundle" action. It collects redacted settings,
filtered logs, catalog metadata, title cache, protection list, history and version
information into a fresh request-owned directory. It never includes Google OAuth tokens,
client secrets, access codes and save contents. The directory and archive are
released after preparation; an open download descriptor expires through the
existing background maintenance. Opening a tab or GET does not create a bundle.

Do not attach RAW save backups to support issues.

Review a bundle before sharing: game names, profile labels, dates and paths may
still be personal. Filtering secrets does not anonymize an entire diagnostic.
If a write result is uncertain, preserve the original evidence and do not retry
or run Cleanup. Donations are optional and never required for support.
